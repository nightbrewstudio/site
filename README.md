# nightbrew-site

Site institucional de nightbrew.com.br. Next.js + Tailwind, mesma tipografia e paleta da madrugada do site do Cada Fase (`lemne-web`).

- `npm run dev` / `npm run build`
- Hospedagem: Vercel, projeto ligado a este repositório (`nightbrewstudio/site`).
- DNS: Hostinger. Só os registros do site apontam para a Vercel; MX, SPF e DKIM do e-mail ficam na Hostinger.
- Conteúdo público apenas: razão social, CNPJ, cidade, e-mail de contato e links dos apps.
